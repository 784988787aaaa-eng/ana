# الدفتر الذكي — Clean Baseline

هذه الحزمة هي خط الأساس التراكمي الحالي للمشروع، مبنية على آخر نسخة محدثة فقط. التطبيق يبدأ بقاعدة بيانات نظيفة من الإصدار الحالي، ولا يحتوي على مسار Migration لنسخ قواعد بيانات سابقة لأن المنتج لم يدخل الاستخدام الفعلي بعد.

## النسخ الاحتياطي
- الامتداد: `.slb`.
- الاسم التلقائي: `SMN_YYYY-MM-DD.slb`.
- الاسم اليدوي: `SMN_YYYY-MM-DD_HHmm.slb`.
- المجلد: `Documents/الدفتر الذكي/YYYY-MM/`.
- المحتوى مشفر ومحمّي بتوثيق AES-GCM.
- مفتاح استعادة محمول مستقل عن الجهاز يسمح باستعادة النسخة على جهاز آخر عند امتلاك مفتاح الاستعادة.
- الاستعادة لا تغيّر الترخيص أو عداد التجربة أو جلسات السحابة.
- الاستعادة الذرية تتم داخل معاملة Room.
- الأرشيف السحابي يستخدم Google Drive API مباشرة من Android عبر Google Sign-In؛ لا يستخدم وسيط خارجي ولا خادماً وسيطاً ولا DocumentsProvider أو OpenDocumentTree.
- ينشئ Drive البنية `الدفتر الذكي/YYYY-MM/` تلقائياً، مع استعراض كامل وبحث ورفع وتنزيل وحذف واستعادة.
- يدعم الأرشيف السحابي البحث والتنزيل والرفع والحذف المتعدد والاستعادة.
- النسخة اليومية تعاد جدولتها عند حدود اليوم المحلي، وتُرفع للسحابة تلقائياً إذا كانت مساحة السحابة مرتبطة.

## الترخيص
- `ACCOUNT`: ترخيص مدى الحياة مرتبط بكود الحساب، مع تحقق صامت دوري وحد أقصى 30 يوماً عند انقطاع التحقق.
- `LOCAL`: ترخيص مدى الحياة مرتبط بالجهاز عبر مفتاح Android Keystore.
- رمز الترخيص موقع رقمياً، والمفتاح العام فقط موجود داخل التطبيق.
- المفتاح الخاص لا يوجد في التطبيق ولا في المستودع.
- التجربة المجانية: 100 عملية إنشاء معاملة، والاستعادة لا تستهلك منها.
- كود الدعم يتكون من كود الحساب وكود طلب، دون طلب البريد الإلكتروني.

## الأسرار
لا توجد مفاتيح خاصة أو كلمات مرور أو رموز وصول أو ملفات Google/وسيط خارجي سرية داخل `app/src/main`.

## قاعدة البيانات
- Room schema الحالي يبدأ من الإصدار 1 ويحتوي مباشرة على جميع الحقول الحالية.
- لا توجد MIGRATION أو مسارات ترقية من إصدارات قاعدة بيانات سابقة.
- اسم قاعدة البيانات الحالي `aldaftar_clean.db` لضمان خط أساس نظيف أثناء التطوير والاختبار.

## لوحة المفاتيح
- فتح لوحة المفاتيح يتم فقط عندما يطلب حقل إدخال ذلك صراحة.
- لا يتم استخدام `SOFT_INPUT_STATE_ALWAYS_VISIBLE`.
- إغلاق النافذة أو إزالة الحقل من التركيب يؤدي إلى `clearFocus(force = true)` ثم إخفاء لوحة المفاتيح، لمنع بقائها بعد إغلاق الحوار.

## قيود التحقق

- لا تُعتبر نسخة `main` صالحة للنشر لمجرد نجاح البناء؛ بوابة الإصدار تتطلب lint و`testDebugUnitTest` و`connectedDebugAndroidTest` ثم بناء Release APK/AAB والتحقق من توقيع APK.
- يتم تنفيذ بوابة الإصدار تلقائياً عبر GitHub Actions عند كل push إلى `main`.
- يجب اعتبار أي فشل في الاختبارات أو التوقيع أو بناء الـAAB مانعاً للنشر.
- الاختبارات التي تحتاج أجهزة فعلية/OEM keyboards/قياسات الأداء أو اختبار التثبيت من Google Play تظل اختبارات قبول خارجية ولا يمكن إثباتها من static source review وحده.
